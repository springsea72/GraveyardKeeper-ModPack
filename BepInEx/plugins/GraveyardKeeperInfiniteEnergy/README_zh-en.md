# GraveyardKeeperInfiniteEnergy

## 简体中文

### 功能

让玩家能量/精力保持满值，并让消耗能量的检查直接通过。砍树、挖矿、挖掘、制作、冲刺、攻击等常见行动都会受益。

### 配置文件

`BepInEx/config/local.chunhai.graveyardkeeper.infiniteenergy.cfg`

当前配置：

```ini
KeepEnergyFull = true
PreventEnergyDecrease = true
SkipSpendChecks = true
```

## English

### Feature

Keeps the player's energy/stamina full and makes energy-spending checks pass. Common actions such as chopping, mining, digging, crafting, dashing, and attacking are covered.

### Configuration File

`BepInEx/config/local.chunhai.graveyardkeeper.infiniteenergy.cfg`

Current settings:

```ini
KeepEnergyFull = true
PreventEnergyDecrease = true
SkipSpendChecks = true
```
