# GraveyardKeeperToolDurabilityGuard

## 简体中文

### 功能

防止斧头、十字镐、铁铲在使用时损失耐久。插件按工具类型识别，因此这些工具的多个级别都会生效。

### 配置文件

`BepInEx/config/local.chunhai.graveyardkeeper.tooldurabilityguard.cfg`

当前配置：

```ini
ProtectAxes = true
ProtectPickaxes = true
ProtectShovels = true
```

## English

### Feature

Prevents axes, pickaxes, and shovels from losing durability when used. The plugin checks tool categories, so all tiers of those tools are covered.

### Configuration File

`BepInEx/config/local.chunhai.graveyardkeeper.tooldurabilityguard.cfg`

Current settings:

```ini
ProtectAxes = true
ProtectPickaxes = true
ProtectShovels = true
```
