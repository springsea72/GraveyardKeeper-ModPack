# GraveyardKeeperFastMovement

## 简体中文

### 功能

提高玩家移动速度。当前速度倍率为 `1.5`，即原速度的 150%。实现方式仿照游戏内速度药水使用的 `speed_buff` 参数。

### 配置文件

`BepInEx/config/local.chunhai.graveyardkeeper.fastmovement.cfg`

当前配置：

```ini
EnableFastMovement = true
SpeedMultiplier = 1.5
StackWithSpeedPotion = true
```

## English

### Feature

Increases player movement speed. The current multiplier is `1.5`, meaning 150% of the original speed. It uses the same `speed_buff` style logic as the base game's speed potion.

### Configuration File

`BepInEx/config/local.chunhai.graveyardkeeper.fastmovement.cfg`

Current settings:

```ini
EnableFastMovement = true
SpeedMultiplier = 1.5
StackWithSpeedPotion = true
```
