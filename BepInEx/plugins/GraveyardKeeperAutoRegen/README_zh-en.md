# GraveyardKeeperAutoRegen

## 简体中文

### 功能

在非睡觉期间自动回复玩家生命值。当前回血速度为正常睡觉回血速度的 `0.2` 倍。

### 配置文件

`BepInEx/config/local.chunhai.graveyardkeeper.autoregen.cfg`

当前配置：

```ini
EnableAutoRegen = true
SleepRateMultiplier = 0.2
RegenWhilePaused = false
RegenDuringSleepGui = false
LogHeals = false
```

## English

### Feature

Regenerates player HP outside sleeping. The current regeneration speed is `0.2` times the normal sleep healing rate.

### Configuration File

`BepInEx/config/local.chunhai.graveyardkeeper.autoregen.cfg`

Current settings:

```ini
EnableAutoRegen = true
SleepRateMultiplier = 0.2
RegenWhilePaused = false
RegenDuringSleepGui = false
LogHeals = false
```
