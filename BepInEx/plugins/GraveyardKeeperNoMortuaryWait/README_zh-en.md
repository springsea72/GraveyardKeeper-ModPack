# GraveyardKeeperNoMortuaryWait

## 简体中文

### 功能

取消太平间相关等待时间：

- 防腐台和二级防腐台的注射液操作立即完成。
- 通过地图远程控制太平间解剖台时，消耗“灵魂的感激”的远程解剖操作立即完成。

插件仍走游戏原本的完成逻辑，材料、资源、产物、尸体/器官状态和结束脚本都由原游戏处理。

### 配置文件

`BepInEx/config/local.chunhai.graveyardkeeper.nomortuarywait.cfg`

当前配置：

```ini
InstantEmbalmingTable = true
InstantRemoteAutopsyTable = true
VerboseLogging = false
```

## English

### Feature

Removes mortuary-related waiting time:

- Embalming fluid operations on embalming table I and II finish immediately.
- Remote autopsy-table operations started through the map/global craft control with Souls' gratitude finish immediately.

The plugin still uses the game's original completion logic, so materials, resources, outputs, body/organ state, and completion scripts are handled by the base game.

### Configuration File

`BepInEx/config/local.chunhai.graveyardkeeper.nomortuarywait.cfg`

Current settings:

```ini
InstantEmbalmingTable = true
InstantRemoteAutopsyTable = true
VerboseLogging = false
```
