# GraveyardKeeperInventoryExpander

## 简体中文

### 功能

扩展玩家主物品栏容量。当前配置为 `TargetSlots = 400`，也就是把玩家主物品栏扩展到 400 格。

### 影响范围

只扩展玩家主物品栏，不扩展箱子、商人库存、背包、世界容器或其他 NPC/设施库存。

### 配置文件

`BepInEx/config/local.chunhai.graveyardkeeper.inventoryexpander.cfg`

当前配置：

```ini
TargetSlots = 400
```

## English

### Feature

Expands the player's main inventory. The current setting is `TargetSlots = 400`, expanding the main player inventory to 400 slots.

### Scope

Only the player's main inventory is expanded. Chests, vendor inventories, bags, world containers, and other NPC/facility inventories are not changed.

### Configuration File

`BepInEx/config/local.chunhai.graveyardkeeper.inventoryexpander.cfg`

Current setting:

```ini
TargetSlots = 400
```
